# How do you sort a DataFrame by one or more columns, and what does the ascending parameter control?

**Difficulty:** Basic · **Levels:** Architect/Principal, Fresher, SDE-1/2, SDE-2/3 · [↑ Pandas DataFrames](<../../../../TOOLS/Python/Python_Language/Pandas_DataFrames.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

To sort a DataFrame in Python using pandas, we use the sort_values method. This method allows us to specify one or multiple columns based on which the DataFrame should be sorted. The ascending parameter controls whether the sorting is done in ascending (default) or descending order.

For a fresher-level explanation:

TL;DR: Use DataFrame.sort_values() with columns and ascending parameters.
