# How would you build a FastAPI endpoint that takes an image and a question and asks a vision-capable model to answer?

**Difficulty:** Intermediate · **Levels:** Fresher, SDE-1/2, SDE-2/3 · [↑ File Uploads and Inference](<../../../../TOOLS/Python/FastAPI/File_Uploads_and_Inference.md>)

## Answer

To create a FastAPI endpoint that processes an image and a question, we need to set up a pipeline where the image is uploaded, sent to a vision-capable model (like a pre-trained neural network), and then the answer generated by the model is returned. Here’s a step-by-step guide:

Set Up FastAPI: We'll start by setting up a basic FastAPI application.
Upload Image: Handle image upload via HTTP POST requests.
Process Image with Model: Use a pre-trained model to process the uploaded image and generate an answer based on the question.
Return Response: Send back the response as JSON.

First, let's summarize the core idea: We need to create a FastAPI endpoint that accepts an image file and a text question, passes these inputs through a vision-capable model, and returns the generated answer. The key steps involve handling files in FastAPI, interfacing with a model, and ensuring robust error handling.
