# How do you customize the OpenAPI schema or add metadata like title and version in FastAPI?

**Difficulty:** Intermediate · **Levels:** Fresher, SDE-1, SDE-1/2, SDE-2/3 · [↑ Custom Responses](<../../../../TOOLS/Python/FastAPI/Custom_Responses.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

To customize the OpenAPI schema in FastAPI, you need to modify the API's metadata such as adding a title and version. This process involves both configuring the FastAPI app directly and using decorators or additional parameters to specify your desired schema details. Let's break down how we can achieve this step-by-step.

First, it’s important to understand that FastAPI uses OpenAPI (formerly known as Swagger) by default for generating interactive API documentation. The title and version are metadata fields that help identify the API; setting them correctly improves clarity and maintainability of your API.

#### Triaging the Question

The question is essentially asking how to set custom metadata in an OpenAPI schema generated by FastAPI. This involves understanding where you can inject these values programmatically or through configuration settings.

#### First-Principles Solution

Configuring the Application:

You can configure the title and version directly via the title and version parameters when creating your FastAPI app instance.

Decorating API Endpoints:

You can also use decorators to add more detailed metadata about individual endpoints.

Customizing the OpenAPI Schema:

If you need finer control over the schema, you can customize it using Pydantic models or by directly modifying the OpenAPI object returned by FastAPI.
Step-by-Step Solution

Setting Global Metadata:

PYTHON
from fastapi import FastAPI

app = FastAPI(title="My Awesome API", version="0.1.0")

Decorating Endpoints for More Details:

You can add more metadata to specific endpoints using the tags and description parameters in route decorators.
PYTHON
from fastapi import APIRouter, Path

router = APIRouter()

@router.get("/items/{item_id}", tags=["Items"], description="Retrieve an item by ID.")
async def read_item(item_id: int = Path(...)):
    return {"item_id": item_id}

Customizing the OpenAPI Schema:

For more detailed customization, you can use Pydantic models or directly modify the OpenAPI object.
PYTHON
from fastapi.openapi.utils import get_openapi

def custom_openapi():
    if app.openapi_schema:
        return app.openapi_schema
    openapi_schema = get_openapi(
        title="My Awesome API",
        version="0.1.0",
        routes=app.routes,
    )
    app.openapi_schema = openapi_schema
    return app.openapi_schema

app.openapi = custom_openapi

Running and Testing:

After setting up your metadata, run the application and visit http://localhost:8000/docs or http://localhost:8000/redoc to see the generated documentation.
