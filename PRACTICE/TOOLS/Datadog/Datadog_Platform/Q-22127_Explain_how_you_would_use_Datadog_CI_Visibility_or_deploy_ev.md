# Explain how you would use Datadog CI Visibility or deploy events to overlay releases on your monitoring timeline.

**Difficulty:** Intermediate · **Levels:** SDE-1/2, SDE-2/3 · [↑ Alert Automation and Runbooks](<../../../../TOOLS/Datadog/Datadog_Platform/Alert_Automation_and_Runbooks.md>)

## Answer

To effectively integrate Datadog CI/CD visibility and deploy events into your monitoring timeline, we need to understand the core objectives: correlating release-related metrics with real-time application performance. This involves setting up a system where each code deployment is tracked, its impact on application health is monitored in near-real time, and anomalies are quickly identified.

First, let's break down what Datadog CI/CD visibility and deploy events can provide:

CI/CD Visibility: Provides insights into the state of your continuous integration and delivery pipelines. This includes build statuses, deployment times, and any issues that arise during deployments.
Deploy Events: These are specific alerts or notifications generated by Datadog when a new release is deployed.

Here’s how we can achieve this in practice:

Setting Up CI/CD Integration:

Ensure your CI/CD pipeline pushes metadata about each deployment to Datadog. This typically includes the deployment environment (staging, production), commit hash, and build number.
Use Datadog's events API or SDKs available for popular CI tools like Jenkins, GitHub Actions, GitLab, etc., to send this information.

Configuring Deploy Events in Datadog:

Create a custom event type called "deploy" or something similar to categorize these events.
Set up tags such as environment, deployment_id, and commit_hash to help filter and group the data effectively.

Overlaying Releases on Monitoring Timeline:

Use Datadog’s Anomaly Detection or Real User Monitoring (RUM) to automatically identify issues related to a specific release.
Utilize Datadog’s dashboard capabilities to create visualizations that show application performance metrics before, during, and after deployments.

Correlating Data:

Implement correlation rules in Datadog to automatically link deploy events with relevant metrics. For example, if an anomaly occurs shortly after a deployment, Datadog can flag this for review.
Set up alerts that notify the team when a new release is deployed and any issues arise within a short window post-deployment.

**Code:**

```python
# Example Python code snippet using Datadog SDK to send deploy event
from datadog import initialize, api

options = {'api_key': 'YOUR_API_KEY', 'app_key': 'YOUR_APP_KEY'}
initialize(**options)

event_message = "New release deployed in staging environment"
tags = ['environment:staging', 'deployment_id:12345']
api.Event.create(message=event_message, tags=tags)
```
