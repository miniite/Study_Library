# What is the difference between .NET Framework, .NET Core, and modern .NET (5+)?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1, SDE-1/2, SDE-2/3 · [↑ JIT vs AOT Compilation](<../../../../TOOLS/DotNet/DotNet_Platform/JIT_vs_AOT_Compilation.md>)

## Answer

The differences between .NET Framework, .NET Core, and modern .NET (5+) are rooted in their design philosophies, runtime environments, and target use cases. In a nutshell:

.NET Framework: This is the original .NET platform developed by Microsoft, targeting Windows. It includes both the Common Language Runtime (CLR) and a large framework library.
.NET Core: An open-source and cross-platform version of the .NET Framework, designed to be lightweight and modular with a focus on performance and flexibility across multiple platforms.
Modern .NET (5+): A continuation of the evolution towards modern, cloud-native development, integrating both .NET Core and full .NET Framework into a single platform. It emphasizes simplicity and ease of use.
