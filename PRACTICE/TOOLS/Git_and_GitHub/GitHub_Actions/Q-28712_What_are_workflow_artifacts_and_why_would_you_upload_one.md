# What are workflow artifacts and why would you upload one?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1/2, SDE-2/3 · [↑ Pinning Third-party Actions](<../../../../TOOLS/Git_and_GitHub/GitHub_Actions/Pinning_Third-party_Actions.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

TL;DR: Workflow artifacts in GitHub Actions are outputs generated by your CI/CD pipeline that can be stored, reused, or shared across different steps within a single workflow or even between multiple workflows. Uploading an artifact is crucial because it allows you to maintain state and pass data from one job to another, enabling more complex pipeline configurations.

#### Triage
The question is asking about the concept of GitHub Actions artifacts and why they are valuable in the context of CI/CD pipelines. Essentially, we need to understand what artifacts are, their purpose, and how they benefit us when building our workflows.

Step-by-Step Solution from First Principles:

Definition of Workflow Artifacts: An artifact is any file or data produced by a job in a GitHub Actions workflow. These files can include build outputs, test results, configuration files, or any other relevant content that needs to be saved and reused later.

Purpose: The primary purpose of uploading an artifact is to store information generated during the execution of your pipeline, making it accessible for future steps within the same run, or even across different runs. This can include:

Build artifacts (e.g., compiled binaries, package files)
Test results
Configuration settings
Log files

Why Upload Artifacts:

Data Sharing: You might need to share certain outputs from one step with another step in the same run or across different runs.
State Preservation: If a job fails, you can still access its output for troubleshooting purposes.
Dependency Management: For complex pipelines, artifacts act as dependencies that can be reused without re-running previous steps.

#### Example Scenario
Suppose you have a CI/CD pipeline that builds and tests a Node.js application. The first step is to run npm install and then compile the source code into a .dist directory. You can configure this job to save its output as an artifact, which will be available for subsequent steps such as running unit tests or deploying the application.

Steps to Upload Artifacts:

Define a jobs section in your GitHub Actions workflow file.
Within each job, use the steps section to define commands and actions.
Use the uses: actions/upload-artifact@v3 action to upload specific files as artifacts.

#### Example
Workflow Configuration:

YAML
name: Node.js CI

on: [push]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout repository
      uses: actions/checkout@v2

    - name: Install dependencies
      run: npm install

    - name: Build and save artifacts
      run: make dist
      env:
        SOME_VAR: "value"
      # Save the output of 'make dist' as an artifact.
      - name: Upload artifact
        uses: actions/upload-artifact@v3
        with:
          name: build-output
          path: .dist

  test:
    runs-on: ubuntu-latest
    needs: [build]

    steps:
    - name: Checkout repository
      uses: actions/checkout@v2

    # Use the artifact from the previous job.
    - name: Download artifact
      uses: actions/download-artifact@v3
      with:
        name: build-output

#### Closing Summary
Uploading artifacts in GitHub Actions is a powerful feature that allows you to manage and reuse data generated during different stages of your CI/CD pipeline. It helps in maintaining state, sharing information between steps, and simplifying complex workflows.

#### Common Mistakes/Follow-Ups

Not Using Artifacts: One common mistake is forgetting to upload necessary artifacts, leading to redundant or repeated work.
Misconfigured Paths: Another issue can be incorrectly specifying the paths for artifact upload/download.
Overuse of Artifacts: While useful, over-relying on artifacts can sometimes complicate your pipeline. Ensure they are used judiciously.
