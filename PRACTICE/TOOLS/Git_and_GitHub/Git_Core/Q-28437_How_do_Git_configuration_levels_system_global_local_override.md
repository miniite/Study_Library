# How do Git configuration levels (system, global, local) override each other, and where does each one live?

**Difficulty:** Intermediate · **Levels:** Fresher, SDE-1/2, SDE-2/3 · [↑ Git vs GitHub](<../../../../TOOLS/Git_and_GitHub/Git_Core/Git_vs_GitHub.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

In Git and GitHub, configurations can be set at three different levels: system, global, and local. These levels are hierarchical in nature, with the highest level (system) taking precedence over lower levels (global/local). The key idea here is to understand how these settings interact and where they reside.
