# How do you configure your Git username and email, and what is the difference between --global and --local config?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1, SDE-1/2, SDE-2/3 · [↑ Git vs GitHub](<../../../../TOOLS/Git_and_GitHub/Git_Core/Git_vs_GitHub.md>)

## Answer

When setting up Git on a new machine or initializing a repository, configuring your username and email is essential to ensure that you are properly identified in commit history. This setup can be done with either global or local configuration options. Here's a quick overview of how these configurations work:

Global Configuration: Setting the username and email globally will apply these values to all repositories on your machine.
Local Configuration: Configuring these settings locally will only affect the specific repository.
