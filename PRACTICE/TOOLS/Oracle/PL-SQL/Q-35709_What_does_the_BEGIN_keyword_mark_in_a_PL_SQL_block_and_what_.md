# What does the BEGIN keyword mark in a PL/SQL block and what must always follow it?

**Difficulty:** Basic · **Levels:** Fresher · [↑ Functions in SQL vs PL/SQL](<../../../../TOOLS/Oracle/PL-SQL/Functions_in_SQL_vs_PLSQL.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

The BEGIN keyword in a PL/SQL block marks the start of the executable part of the code. It signifies that everything following it until the corresponding END; is the body of the procedure, function, or anonymous block. This keyword must always be followed by one or more statements.
