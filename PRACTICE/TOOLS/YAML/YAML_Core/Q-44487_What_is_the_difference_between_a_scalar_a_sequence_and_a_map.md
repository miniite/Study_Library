# What is the difference between a scalar a sequence and a mapping in YAML terminology?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1/2, SDE-2/3 · [↑ YAML and JSON](<../../../../TOOLS/YAML/YAML_Core/YAML_and_JSON.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

In YAML, scalars, sequences, and mappings are fundamental data types that define how data can be structured and represented. A scalar is a single value, such as a string or an integer; a sequence is a list of values; and a mapping is a collection of key-value pairs. Understanding these concepts is crucial for writing effective YAML files.

These distinctions allow you to create complex configurations with precise control over data structure. For example, consider the scenario where you need to define network settings in a server configuration file.
