# Why is returning source citations in a RAG API response useful, and how would you structure them in the JSON?

**Difficulty:** Intermediate · **Levels:** Fresher, SDE-1/2, SDE-2/3 · [↑ Partial Failure in Fan-out APIs](<../../../../07_Distributed_Systems_and_Design/APIs/REST_APIs/Partial_Failure_in_Fan-out_APIs.md>)

## Answer

Returning source citations in a Retrieval-Augmented Generation (RAG) API response is useful because it enhances the transparency and trustworthiness of the generated content. By providing references to where the information came from, users can verify the accuracy of the data and understand its origin. This is particularly important for applications such as educational tools, news aggregators, or any context where the credibility of the information is paramount.

To structure source citations in JSON, we need to define a clear format that captures key details about each reference. Let's break down the process step by step from first principles.

**Code:**

```json
{
  "response": "This is an example response generated by the RAG system.",
  "sources": [
    {
      "type": "web",
      "url": "https://example.com/article1",
      "title": "Article Title 1",
      "author": "Author Name",
      "timestamp": "2023-09-25T14:48:00Z"
    },
    {
      "type": "pdf",
      "url": "https://example.com/file.pdf",
      "title": "Research Paper Title 2",
      "author": ["Author A", "Author B"],
      "timestamp": "2023-09-15T08:30:00Z"
    }
  ]
}
```
