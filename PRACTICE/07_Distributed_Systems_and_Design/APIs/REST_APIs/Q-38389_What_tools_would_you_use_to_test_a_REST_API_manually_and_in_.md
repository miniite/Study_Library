# What tools would you use to test a REST API manually and in automated tests?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1, SDE-1/2, SDE-2/3 · [↑ API Versioning and Deprecation](<../../../../07_Distributed_Systems_and_Design/APIs/REST_APIs/API_Versioning_and_Deprecation.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

When testing a REST API, both manual and automated approaches are crucial. For manual testing, we rely on basic tools like Postman or cURL. Automated testing typically involves using frameworks like JUnit, PyTest, or Jest in combination with tools such as Katalon Studio or Selenium for more complex scenarios.
