# The deploy step succeeded but the app is showing errors. Where would you look first as a fresher?

**Difficulty:** Intermediate · **Levels:** Architect/Principal, Fresher, SDE-1/2, SDE-2/3 · [↑ Deployment Verification](<../../../../10_DevOps_and_Platform/Delivery/CI_CD/Validating_Pipeline_Changes/Deployment_Verification.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

As a DevOps fresher, if I encounter an issue where the deployment step has successfully completed but the application is still displaying errors, my initial approach would be focused on understanding the nature of the error and systematically isolating potential causes. The first things to check are usually straightforward, such as verifying environment configurations or ensuring that the correct code was deployed.

The question essentially probes your ability to diagnose issues methodically and understand the layers involved in CI/CD pipelines. Here’s a step-by-step breakdown:

Verify Environment Configuration: Ensure that the application is configured correctly for the target environment (development, staging, production).
Check Deployment Logs: Review logs from the deployment process to identify any errors or warnings.
Inspect Application Logs: Analyze logs generated by the deployed application to understand what went wrong during runtime.

**Code:**

```bash
# Example of checking logs
kubectl logs <deployment-pod> -n <namespace>
```
