# What is data drift and give an example of how it could break a downstream report.

**Difficulty:** Deep · **Levels:** Fresher, SDE-1/2, SDE-2/3 · [↑ Detecting Unit Changes](<../../../../02_Data_Engineering/Data_Quality/Validation/Detecting_Unit_Changes.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

Data drift refers to changes in the statistical properties of data over time, which can render previously trained models or algorithms ineffective. This concept is critical in maintaining the quality and reliability of data-driven decisions. For example, consider a scenario where you are using a machine learning model to predict customer churn based on demographic and behavioral data.

Imagine an e-commerce company that has been using this model for several months. Initially, the model was trained on a dataset with demographics like age (ranging from 18-60), purchase frequency, and average order value. The report generated by this model helps in identifying high-risk customers who are likely to churn. However, over time, due to various factors such as seasonal changes or marketing campaigns, the demographic distribution shifts significantly—new younger customers join at a higher rate than older ones, and their purchasing behavior is different.

Let's take a closer look:

Initial Model Training: The model was trained on data where the age range was 18-60 with an average purchase frequency of once every two weeks.
Data Over Time: After six months, due to new marketing campaigns targeting younger customers (say, between 18-35), the dataset now includes a significant number of younger individuals who have higher purchase frequencies but also different spending patterns.

Now, let’s dive into an example scenario:

Impact on Report

The initial model, when applied to the drifted data, might still output predictions based on the older training dataset. For instance:

A younger customer with a higher purchase frequency and spending pattern (which aligns more closely with the new demographic) is predicted as having a low churn risk because the model was trained on an older age range.

This misclassification could lead to incorrect decisions, such as not intervening when these customers are actually at high risk of churning. Over time, this could result in significant financial losses for the company.

#### Triaging the Question

The interviewer is probing your understanding of data drift and its potential impact on downstream reports and models. They want you to demonstrate:

#### First Principles Solution
Detection: Implement statistical tests like Kolmogorov-Smirnov (KS) test or Chi-square test to detect significant shifts in the distribution of data over time.
Validation Checks: Regularly validate the model’s performance on a holdout dataset and compare it with new incoming data using drift detection techniques.
Retraining: Automate retraining of models when data drift is detected to ensure they remain accurate.
Monitoring: Use real-time monitoring tools to track changes in key metrics that could indicate data drift.

#### Closing Summary

Data drift can severely impact the accuracy and reliability of downstream reports, leading to incorrect business decisions. It’s crucial to implement robust validation checks, periodic retraining, and real-time monitoring to address these issues effectively.

**Code:**

```python
from scipy.stats import ks_2samp

# Example of using KS test for drift detection
def detect_drift(data_old, data_new):
    result = ks_2samp(data_old['PurchFreq'], data_new['PurchFreq'])
    return result.pvalue < 0.05
```
