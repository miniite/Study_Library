# You inherit an S3 bucket with 2 years of Parquet files, no catalog, no partition scheme, and no owner. Give me your first two weeks of work to make it queryable and trustworthy.

**Difficulty:** Intermediate · **Levels:** Architect/Principal, SDE-1/2, SDE-2/3 · [↑ Warehouse Vendor Exit Strategy](<../../../../04_Data_Architecture_and_Strategy/Architecture_Patterns/Data_Architecture/Layered_Pipelines_Bronze_Silver_Gold/Warehouse_Vendor_Exit_Strategy.md>)

## Answer

To tackle this challenge effectively, I would focus on establishing a robust data architecture that ensures the S3 bucket's contents are queryable, maintainable, and trustworthy over time. My approach involves setting up an AWS Data Lake structure using Parquet files stored in S3, creating an Athena table to enable ad-hoc querying, implementing a Glue Catalog for metadata management, and establishing governance policies.

The first two weeks will be dedicated to the following steps:

Assessment and Preparation: Understand the data schema, volume, and key usage patterns.
Data Organization: Create a structured directory hierarchy in S3 to organize Parquet files into partitions.
Metadata Management: Use AWS Glue to catalog the data for better metadata management.
Querying Layer: Set up Amazon Athena to query the organized data.

Let’s break this down step-by-step:

#### Triage
What is being asked and what we are probing

The question requires setting up a queryable environment from scratch in an S3 bucket containing unstructured Parquet files. The key aspects include ensuring data organization, metadata management, and making the data accessible via a querying layer.

Step 1: Assessment and Preparation (Day 1-2)
Objective:

Understand the current state of the data, including schema, volume, and usage patterns.

Actions:
Examine Data: Use tools like S3 Browser or AWS CLI to inspect the Parquet files in the bucket.
Identify Schema: Determine the structure of the Parquet files (e.g., columns, types).
Usage Patterns: Identify common queries and use cases.
Step 2: Data Organization (Day 3-5)
Objective:

Organize data into a structured hierarchy to facilitate querying.

Actions:
Create Directory Structure: Organize the Parquet files based on time or other relevant criteria (e.g., year/month/day).
Move Files: Use AWS CLI commands to move and rename files as needed.
Step 3: Metadata Management (Day 6-8)
Objective:

Catalog the data using AWS Glue for metadata management.

Actions:
Create Glue Crawler: Configure a crawler in AWS Glue to discover the schema of the Parquet files.
Run Crawler: Execute the crawler to automatically generate a table definition.
Review and Validate: Review the generated schema and validate it against the actual data.
Step 4: Querying Layer (Day 9-10)
Objective:

Set up Amazon Athena to query the organized data.

Actions:
Create Database in Glue Catalog: Use AWS Glue console or API to create a database for the Athena tables.
Define Athena Table: Create an Athena table pointing to the S3 location using the schema generated by the crawler.
Test Queries: Run sample queries on Athena to ensure everything is working as expected.

#### Closing Summary
and Common Mistakes

By the end of these two weeks, we should have a fully functional queryable data lake with organized Parquet files in S3, metadata managed via AWS Glue, and a querying layer through Amazon Athena. Key mistakes to avoid include not properly organizing the data structure, failing to validate the schema, or neglecting governance policies.

#### Common Mistakes/Follow-Ups
Failing to plan for ongoing maintenance and governance.
Not considering security and access controls early in the process.
Ignoring performance optimization when setting up Athena tables.

```python
# Example of creating a Glue Crawler
import boto3

glue_client = boto3.client('glue')

response = glue_client.create_crawler(
    Name='my-crawler',
    Role='arn:aws:iam::123456789012:role/service-role/MyGlueServiceRole',
    DatabaseName='s3-parquet-database',
    Targets={
        'S3Targets': [
            {
                'Path': 's3://my-data-lake/year=2023/month=01/',
                'Exclusions': []
            }
        ]
    },
    Configuration='{"Version": 1.0, "CrawlerOutput": {"Partitions": {"AddOrUpdateBehavior": "InheritFromTable"}, "Tables": {"AddOrUpdateBehavior": "InheritFromTable"}}}'
)
```
