# How would you use an AI assistant to write unit tests for an existing function?

**Difficulty:** Intermediate · **Levels:** Fresher, SDE-1, SDE-1/2, SDE-2/3 · [↑ Trust Boundaries for AI Generated Code](<../../../../09_Software_Engineering/Developer_Productivity/AI_Assisted_Coding/Trust_Boundaries_for_AI_Generated_Code.md>)

## Answer

When using an AI assistant like Copilot or Cursor to generate unit tests for an existing function, the key idea is to leverage its ability to analyze and understand the code structure and functionality. The core solution involves guiding the AI through a structured approach that ensures comprehensive test coverage while avoiding common pitfalls. Here’s how you can use an AI-assisted coding tool effectively:

#### Triage

The question is essentially asking about a strategy for using an AI assistant (like Copilot or Cursor) to automatically generate unit tests for an existing function. The interviewer is likely probing your understanding of:

Code analysis: How well you understand the existing code.
Test generation: Your ability to formulate and guide test cases effectively.
Integration strategy: How you would integrate the AI tool into your development process.

#### First-Principles Solution

To use an AI-assisted coding tool for writing unit tests, follow these steps:

Understand the Functionality:

Analyze the function to understand its input and output.
Determine edge cases, boundary conditions, and typical scenarios.

Guide the Tool:

Use specific prompts like //test or //unit test to guide the AI.
Provide context about what kind of tests you want (e.g., positive/negative, edge cases).

Review and Refine:

After generating initial tests, review them for correctness and completeness.
Modify generated code as needed.

Integrate into Workflow:

Integrate the generated tests into your existing test suite.
Ensure they are properly formatted and integrated with CI/CD pipelines.

#### Example
Walkthrough

Let’s consider a function addNumbers that takes two integers and returns their sum:

PYTHON
def addNumbers(a: int, b: int) -> int:
    return a + b

Step 1: Analyze the Functionality

The function takes two integer inputs.
It returns the sum of these integers.

Step 2: Guide the Tool Using Copilot (or similar), you might prompt it with:

PYTHON
//unit test for addNumbers

def test_addNumbers():
    //test positive case
    assert addNumbers(1, 2) == 3

    //test edge cases
    assert addNumbers(-1, 0) == -1
    assert addNumbers(0, 0) == 0

    //test large numbers
    assert addNumbers(999999, 1) == 1000000

//unit test for negative case

Step 3: Review and Refine Review the generated tests to ensure they cover all possible scenarios. Modify as necessary:

PYTHON
def test_addNumbers():
    assert addNumbers(1, 2) == 3
    assert addNumbers(-1, 0) == -1
    assert addNumbers(0, 0) == 0
    assert addNumbers(999999, 1) == 1000000

def test_negative_case():
    assert addNumbers(-1, -2) == -3

Step 4: Integrate into Workflow Integrate these tests into your existing CI/CD pipeline to ensure continuous testing.

#### Closing Summary
and Common Mistakes/Follow-Ups

Using an AI-assisted coding tool for generating unit tests can significantly speed up the development process. However, it’s crucial to:

Review all generated tests thoroughly.
Ensure proper edge cases are covered.
Integrate seamlessly into your existing test suite.
