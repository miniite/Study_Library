# How do you decide when to accept an AI suggestion versus writing it by hand?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1, SDE-1/2, SDE-2/3 · [↑ Measuring AI Productivity](<../../../../09_Software_Engineering/Developer_Productivity/AI_Assisted_Coding/Measuring_AI_Productivity.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

When deciding whether to accept an AI-assisted coding suggestion or write code manually, a backend SDE-2/3 at a fullstack SDE level needs to consider factors like maintainability, performance, and personal expertise. The key idea is to leverage the strengths of both human intuition and AI capabilities while mitigating potential pitfalls.

#### Triage
What's Being Probed

The interviewer is probing your understanding of:

AI Capabilities: Knowing when an AI suggestion aligns with best practices.
Code Quality Standards: Adhering to coding standards and ensuring maintainability.
Time Management: Balancing the time saved by using AI against potential debugging issues.

#### Assumptions
You have access to a robust AI-assisted coding tool like Copilot or similar.
The codebase follows established conventions and best practices.
Your project timeline allows for some flexibility in initial development stages.
Step-by-Step Solution
1. Evaluate the Suggestion’s Relevance

First, assess whether the suggestion aligns with your current coding context. Consider if:

It adheres to coding standards and conventions.
The suggested code snippet fits seamlessly into the existing architecture.

For example, suppose you are implementing a REST API in Node.js using Express. A Copilot suggestion might propose adding middleware for error handling. This is relevant because it aligns with common practices and improves maintainability.

2. Check for Performance Implications

Next, consider any performance implications of accepting the AI suggestion versus writing code manually. For instance:

Does the suggested code introduce unnecessary complexity?
Will the suggested approach improve or degrade runtime efficiency?

Suppose an AI suggests using a deep learning library to solve a problem that can be adequately handled with simpler algorithms like linear regression. This could lead to over-engineering and slower performance.

3. Consider Code Readability and Maintainability

Ensure the code remains readable and maintainable by checking:

The length and complexity of the suggested code.
Whether the AI suggestion uses a well-understood or commonly used pattern.

For example, if Copilot suggests using complex functional programming constructs when your team is more familiar with imperative coding styles, this could make the code harder to understand for other developers on your team.

4. Assess Your Expertise and Trust in the AI

Evaluate your trust in the AI system:

Are you confident that the suggestion aligns with best practices?
Do you have domain knowledge that suggests a different approach might be better?

If you are working on a complex financial application, for instance, it’s important to double-check any mathematical or financial logic generated by an AI.

#### Closing Summary

In summary, the decision to accept an AI-assisted coding suggestion versus writing code manually should balance time efficiency with maintainability and performance. Always verify that the suggested code adheres to established standards and practices, evaluates potential performance impacts, ensures readability, and aligns with your team’s expertise and project needs.

#### Common Mistakes
Over-reliance on AI suggestions without manual verification.
Ignoring potential performance issues introduced by AI-generated code.
Accepting complex or unconventional solutions without proper context.
