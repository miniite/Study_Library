# Copilot generates a matplotlib figure that's unreadable at report size. How would you prompt it to fix fonts, DPI, and legend placement?

## Answer

To address the issue of an unreadable matplotlib figure generated by Copilot, we need to ensure that the figure's font sizes, DPI (dots per inch), and legend placements are optimized for report size. The key idea is to adjust these parameters in a way that enhances readability without compromising on the quality or content of the plot.

The question is essentially asking how to provide specific instructions to Copilot so it can generate a more readable figure. This involves understanding the current state of the figure and suggesting improvements based on common best practices for report-sized figures.

#### Assumptions

We have access to the figure object generated by Copilot.
The figure's size is appropriate but the elements (like fonts, DPI) need adjustments.

Let's break this down step-by-step:

Identify the Problem: Understand that the main issues are likely related to font sizes and legend placement, as well as possibly inadequate DPI for high-resolution printing or display.

Suggest Adjustments:

Increase Font Sizes: Ensure text elements like axis labels, titles, ticks, and legend entries are large enough to be read.
Optimize DPI: Ensure the figure is generated with a sufficient DPI value so that it looks clear when printed or viewed on high-resolution displays.
Improve Legend Placement: Adjust the position of the legend to avoid overlapping with other plot elements and ensure it remains legible.

#### Cons
truct the Prompt:

"Increase font sizes, especially for axis labels and titles, to a minimum size of 12 points."
"Ensure the DPI is set to at least 150 or higher, depending on the intended use (e.g., printing vs. screen display)."
"Place the legend outside the main plot area if it's causing overlap, ensuring there is enough space around the legend for clarity."

By providing these specific instructions, we can guide Copilot to generate a more readable and usable figure.

**Code:**

```python
# Example of adjusting matplotlib parameters based on suggestions

import matplotlib.pyplot as plt

def adjust_figure(fig):
    # Increase font sizes
    fig.set_size_inches(8, 6)  # Adjust the size if necessary for readability
    plt.rcParams.update({'font.size': 12})  # Set default font size to 12 points

    # Ensure DPI is adequate
    fig.dpi = 150  # Set DPI to at least 150

    # Improve legend placement
    ax = plt.gca()  # Get the current axes
    handles, labels = ax.get_legend_handles_labels()
    ax.legend(handles, labels, loc='upper right', bbox_to_anchor=(1.3, 1))  # Place outside plot area

    return fig
```
