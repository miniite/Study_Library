# What is the difference between an abstract data type and a concrete data structure, with an example?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1, SDE-1/2, SDE-2/3 · [↑ O(1) Randomized Set](<../../../../08_Algorithms_and_Data_Structures/Core/Data_Structures_and_Algorithms/O(1)_Randomized_Set.md>)

## Answer

An abstract data type (ADT) defines a set of operations that can be performed on data without specifying how these operations are implemented. A concrete data structure, on the other hand, is a specific implementation of an ADT using underlying storage mechanisms and programming techniques. For example, a stack is an ADT that supports push and pop operations; whereas, a linked list or array can be used as concrete implementations to achieve this functionality.
