# What are the different types of parameters a stored procedure can accept?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1, SDE-1/2 · [↑ Procedure Parameters](<../../../../01_Databases_and_SQL/Database_Objects/Stored_Procedures/Procedure_Parameters.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

When we talk about the types of parameters that a stored procedure can accept, it's essential to understand that these parameters allow procedures to be more flexible and reusable by accepting inputs during their execution. There are three main types of parameters in SQL: IN, OUT, and INOUT.

TL;DR: Stored procedures can accept IN, OUT, and INOUT parameters, each serving a different purpose based on the need for input or output data.
