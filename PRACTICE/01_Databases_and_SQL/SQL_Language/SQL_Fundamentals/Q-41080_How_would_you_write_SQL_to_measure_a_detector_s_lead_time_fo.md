# How would you write SQL to measure a detector's lead time: for each true-positive flag, the minutes between the flag and the incident it predicted, and summarize the distribution to justify keeping the model?

**Difficulty:** Intermediate · **Levels:** SDE-1/2, SDE-2/3 · [↑ Gaps and Islands](<../../../../01_Databases_and_SQL/SQL_Language/SQL_Fundamentals/Gaps_and_Islands.md>)

## Answer

To measure a detector's lead time in SQL, we need to find the time difference between each true-positive (TP) flag and its corresponding incident. The goal is then to summarize this distribution to assess the performance of the model over different lead times.

Let’s assume our data schema includes two tables:

flags table: Contains information about the flags generated by the detector, including a unique flag ID (flag_id) and the timestamp when the flag was created (flag_time).
incidents table: Contains incident records with a unique incident ID (incident_id) and the timestamp of when the incident occurred (incident_time). Each incident has an associated flag that predicted it.

The key step is to join these tables on the condition that the flag correctly predicts the incident (i.e., each TP flag should have a corresponding incident).

Here’s how you can write the SQL query:

SQL
-- Step 1: Join flags and incidents where the flag_time is less than or equal to the incident_time
WITH predicted_flags AS (
    SELECT
        f.flag_id,
        f.flag_time,
        i.incident_id,
        i.incident_time
    FROM
        flags f
    JOIN
        incidents i ON f.flag_time <= i.incident_time AND i.predicted_flag_id = f.flag_id
),

-- Step 2: Calculate the lead time in minutes for each TP flag
lead_times AS (
    SELECT
        flag_id,
        (incident_time - flag_time) * 1440 AS lead_minutes
    FROM
        predicted_flags
)

-- Step 3: Summarize the distribution of lead times
SELECT
    lead_minutes,
    COUNT(*) AS count
FROM
    lead_times
GROUP BY
    lead_minutes
ORDER BY
    lead_minutes;

This query will provide a summary of the lead time in minutes for each TP flag, grouped by the number of incidents at each lead time. This information can be used to justify whether the model is performing well.
