# How do you read the execution plan of a query in MySQL and what does EXPLAIN output show?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1, SDE-1/2 · [↑ Reading Execution Plans](<../../../../01_Databases_and_SQL/Query_Performance/Execution_Plans/Reading_Execution_Plans.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

When working with databases, understanding how your queries are executed is crucial to optimizing performance. In MySQL, EXPLAIN is a powerful tool that provides insights into the execution plan of a query. It helps you see how the database will process your SQL statement, allowing you to make informed decisions about index usage and other optimizations.
