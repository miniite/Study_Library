# In one sentence what is the core idea behind normalizing a database schema?

**Difficulty:** Basic · **Levels:** Fresher, SDE-1/2, SDE-2/3 · [↑ Normalization Fundamentals](<../../../../01_Databases_and_SQL/Database_Design/Normalization/Normalization_Fundamentals.md>)

> ⚠️ Practice answer, not verified. Some answers contain mistakes; when in doubt, follow the lesson.

## Answer

The core idea behind normalizing a database schema is to eliminate redundant data and ensure that each piece of information is stored in only one place, which helps in reducing data redundancy and improving data integrity.
